Shakti.jl

Shakti.jl is a Julia implementation of the transient subglacial hydrology model Shakti (Sommers et al., 2018). On a regular grid it evolves the water-filled gap between ice and bed and gives the hydraulic head, the water flux and the effective pressure at the ice base. One set of equations covers distributed (laminar) and channelized (turbulent) drainage.

By default the physics represented by the code follows GlaDS-2 (Wells et al., 2026), where cavities can be partly empty and water above the overburden lifts the ice, so 0 ≤ p_w ≤ p_o. Shakti's original model can be selected with keywords to Simulation, shown in the tutorial and run in the Helheim and Drang Drung examples. Channel-wall diffusion from Suhmo (Felden et al., 2023) is also implemented in the code as an option.

The aim is a Shakti fast enough to be coupled to an ice-flow model such as Yelmo over long runs, on CPU and GPU.
